# Project working instructions

- Never remove project files without the user's explicit approval. Temporary build/cache files created by the current task may be cleaned up when needed.
- Make small, verified Git commits as meaningful milestones are completed.
- After each progress commit, provide a short informal X-ready post describing what was built and actually verified.
- Keep the post concise enough for a normal X post, use an approachable builder tone, and do not include secrets, board IDs, local IP addresses, private paths, or unverified claims.
- Target only the Waveshare ESP32-S3-Touch-LCD-5B, SKU 28151, with its 1024×600 display profile unless the user explicitly expands hardware support.
